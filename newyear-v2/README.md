# 跨年勤務配置預覽（newyear-v2）

這是供確認 **整頁版面與勤務操作流程** 的獨立唯讀預覽，不是正式勤務全功能完成，不覆蓋 `newyear/`。

- 沿用根目錄 `style.css`、隊徽、Huninn 與 `.card / .tag / .ghost / .chip`。
- 桌機左側主圖、右側單一「所選位置／勤務」。手機總覽依原活動版面排列，選取後進入同屏查看：直向上圖下資料，橫向左右並列；兩區互不遮擋，「返回全場」退出。選取位置另以唯一紅圈標示，即使對應圖層未開啟仍能辨認。
- 正式管制 `areas`、進駐 `stations` 保留空陣列；無示範人車、名冊或假聯絡資料。搜尋 bounds 沿用舊版，**不是管制範圍**。
- 只有 `Fleet.createFeed` 的 `fleet_data` 唯讀查詢及官方 CCTV 清單／串流；不讀登入 token、不呼叫任何勤務狀態讀寫 API。`preview` 固定為 `true`。
- 人工勤務「待命」僅預設示意、不儲存；定位時效、精確度、速度及軌跡取樣沿用共用 Fleet 規則。所有時間使用 `Ops.formatTime`（台北）。
- 相關鏡頭在同一面板下方播放，保留所選車／點／區資料；切換選取、換片、關閉、返回全場及 pagehide 都釋放播放器。所有鏡頭可展開查找，預設不開鏡頭地圖圖層。
- 正式編組只解析進駐點 `vehicles` 明列車號。區域空間關聯依 GeoJSON Polygon／MultiPolygon（含孔洞），不把相鄰位置當正式指派。
- 官方本年度煙火來源未提供；不拿歷年影片冒充直播。3D 只提供輔助連結。

以任意靜態 HTTP 伺服器從專案根目錄提供檔案，再開啟 `/newyear-v2/`。正式資料、真串流可用性、完整瀏覽器 QA 與部署仍由主線確認。

單元測試：`node --test newyear-v2/tests/duty-core.test.cjs`。
